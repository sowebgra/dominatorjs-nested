# Dominator.js — Nested

**A new way to structure dynamic web interfaces with JavaScript.**

Dominator.js is a lightweight JavaScript framework designed to simplify the creation and manipulation of web applications through a structured, declarative approach.

This repository contains **Dominator.js Nested**, the first publicly released part of the Dominator.js framework.

## About Nested

Nested introduces a structured approach to building web interfaces using JavaScript objects.

Rather than relying entirely on manually writing and manipulating HTML elements, developers can describe interface structures through nested JavaScript objects and let Dominator.js handle their creation.

The objective is to make interface development more structured, readable, and easier to manipulate.

## Getting Started

You don't need to install Node.js, npm, or additional dependencies to try the basic demonstration.

### 1. Download

Clone this repository:

```bash
git clone https://github.com/sowebgra/dominatorjs-nested.git
```

Alternatively, download the repository as a ZIP file directly from GitHub.

### 2. Run the demonstration

Open `index.html` in your browser.

You should immediately see the Hello World demonstration powered by Dominator.js.

## Requirements

- A modern web browser.
- Basic knowledge of JavaScript.
- Basic understanding of HTML and CSS.

No additional JavaScript dependencies are required for the standalone demonstration.

## Philosophy

Dominator.js is built around a simple ambition: make web application development more accessible, structured, and easier to manipulate.

It is designed to give developers greater control over how they create, organize, and manage dynamic web interfaces.
